# 🤖 Asta Bot — بوت واتساب

**Asta Bot** هو بوت واتساب قابل للتخصيص، مبني على Node.js ويعتمد على نظام إضافات (Plugins) لإضافة الأوامر والوظائف بسهولة. يتضمن المشروع لوحة تحكم ويب لإدارة البوت ومتابعة حالته، بالإضافة إلى نظام صلاحيات ومراقبة واسترداد تلقائي.

> **الإصدار:** 1.0.0  
> **النواة:** Asta  
> **الاسم الظاهر للبوت:** Khalid

---

## ✨ المميزات

- 💬 بوت واتساب يعمل من خلال WhatsApp Web.
- 🧩 نظام Plugins لإضافة الأوامر وتنظيمها.
- 🔄 إعادة تحميل الإضافات دون الحاجة إلى إعادة تشغيل البوت.
- 👑 نظام صلاحيات متعدد المستويات لإدارة الأوامر الحساسة.
- 🖥️ لوحة تحكم ويب لمتابعة البوت وإدارته.
- 📊 إحصائيات ومراقبة لحالة التشغيل.
- 📝 سجلات ومتابعة للأحداث.
- ⏰ جدولة المهام من لوحة التحكم.
- 💾 نسخ احتياطية واستعادة بيانات لوحة التحكم.
- 🛡️ حماية للجلسات وبيانات لوحة التحكم ومفاتيح التشفير.
- ❤️ Watchdog لمراقبة صحة العملية ومحاولة الاسترداد عند حدوث مشاكل.
- 🌐 واجهة عربية RTL مع دعم اللغة الإنجليزية.
- 🌙 دعم الوضع الفاتح والداكن في لوحة التحكم.

---

## 📋 المتطلبات

قبل التثبيت، تأكد من توفر:

- **Node.js 18 أو أحدث**
- **npm**
- حساب واتساب لاستخدامه مع البوت
- اتصال بالإنترنت

للاستضافة المستمرة يمكن استخدام **PM2** بشكل اختياري.

## 🚀 التثبيت والتشغيل

### 1. تحميل المشروع

من صفحة المستودع على GitHub اختر **Code → Clone** وانسخ رابط المستودع، ثم نفّذ:

```bash
git clone <رابط-المستودع>
cd <مجلد-المشروع>
```

### 2. تثبيت الاعتماديات

```bash
npm install
```

### 3. إعداد ملف البيئة

انسخ ملف الإعدادات النموذجي:

```bash
cp .env.example .env
```

> في Windows يمكن نسخ الملف يدويًا باسم `.env`.

يمكن تعديل إعدادات لوحة التحكم والمراقبة من ملف `.env`.

**لا ترفع ملف `.env` إلى GitHub.**

### 4. تشغيل البوت

```bash
npm start
```

في أول تشغيل، اتبع التعليمات الظاهرة في الطرفية لربط حساب واتساب باستخدام طريقة الربط المتاحة في إعدادات المشروع.

بعد نجاح الربط يتم حفظ بيانات جلسة واتساب محليًا داخل مجلد:

```text
ملف_الاتصال/
```

هذا المجلد **خاص** ولا يجب مشاركته أو رفعه إلى GitHub.

## 🖥️ لوحة التحكم

لوحة التحكم مفعلة افتراضيًا وتعمل على:

```text
http://127.0.0.1:8787
```

يمكن تغيير المضيف والمنفذ من ملف `.env` عبر:

```env
DASHBOARD_ENABLED=true
DASHBOARD_HOST=127.0.0.1
DASHBOARD_PORT=8787
```

### تسجيل الدخول لأول مرة

يمكن تحديد بيانات المسؤول الأولية داخل `.env`:

```env
DASHBOARD_ADMIN_USER=
DASHBOARD_ADMIN_PASSWORD=
```

أو تركها فارغة ليتم إنشاء كلمة مرور عشوائية عند أول تشغيل وعرضها مرة واحدة في الطرفية.

**استخدم كلمة مرور قوية ولا تشارك بيانات دخول لوحة التحكم.**

### أهم أقسام لوحة التحكم

- نظرة عامة وحالة البوت
- الإحصائيات
- السجلات
- إدارة الإضافات
- الجدولة
- النسخ الاحتياطية
- التنبيهات
- سجل التدقيق
- إدارة مستخدمي لوحة التحكم
- الإعدادات

## 🧩 الإضافات (Plugins)

توجد أوامر البوت داخل مجلد:

```text
plugins/
```

وتنقسم الإضافات إلى فئات، مثل:

| الفئة | الاستخدام |
|---|---|
| `العاب` | الألعاب |
| `ادوات` | الأدوات والخدمات |
| `اعدادات` | إعدادات البوت |
| `النقابات` | إدارة النقابات والمجتمعات |
| `جروب` | إدارة المجموعات |
| `النخبة` | إدارة أعضاء النخبة |
| `المطور` | أدوات الإدارة والتطوير |

يمكن للنظام إعادة تحميل الإضافات التي تم تعديلها أثناء التشغيل وفقًا لآلية التحميل الموجودة في المشروع.

## 👑 نظام الصلاحيات

يدعم البوت عدة مستويات من الصلاحيات:

**المالك الأساسي → المالك → نائب المالك → المطور → النخبة → المستخدم**

تختلف الصلاحيات المتاحة حسب مستوى المستخدم، ويتم فحص الصلاحيات قبل تنفيذ الأوامر الحساسة.

كما تحتوي لوحة التحكم على نظام صلاحيات مستقل عن صلاحيات البوت، ويشمل مستويات مثل:

- Admin
- Manager
- Viewer
- Pending

## 🌐 النشر على خادم VPS أو جهاز يعمل باستمرار

يمكن تشغيل البوت باستخدام PM2:

```bash
npm install -g pm2
pm2 start index.js --name asta-bot
pm2 save
pm2 startup
```

بعد أي تحديث:

```bash
git pull
npm install
pm2 restart asta-bot
```

### ⚠️ الوصول إلى لوحة التحكم من الإنترنت

الافتراضي هو:

```env
DASHBOARD_HOST=127.0.0.1
```

وهذا أكثر أمانًا عند الاستخدام المحلي.

لا تجعل لوحة التحكم متاحة على الإنترنت مباشرة إلا بعد إعداد طبقة حماية مناسبة مثل Reverse Proxy وHTTPS والتحكم في الوصول.

## 🔄 التحديث

قبل تحديث نسخة تعمل على خادم، يُفضّل أخذ نسخة احتياطية من بيانات التشغيل الخاصة بك.

ثم:

```bash
git pull
npm install
```

وإذا كان البوت يعمل عبر PM2:

```bash
pm2 restart asta-bot
```

ملفات `.env` وجلسة واتساب وبيانات التشغيل المحلية لا يتم تحديثها من Git لأنها مستبعدة من المستودع.

## 🛠️ استكشاف الأخطاء

### البوت لا يتصل بواتساب

- تأكد من اتصال الإنترنت.
- راجع الرسائل الظاهرة في الطرفية.
- إذا أصبحت جلسة واتساب غير صالحة، يمكن إعادة إنشاء الجلسة ثم إعادة الربط.

### لوحة التحكم لا تفتح

تحقق من:

```env
DASHBOARD_ENABLED=true
DASHBOARD_HOST=127.0.0.1
DASHBOARD_PORT=8787
```

وتأكد أن المنفذ غير مستخدم من برنامج آخر.

### إضافة لا تعمل

تحقق من سجل التشغيل لمعرفة سبب فشل تحميل الإضافة، وتأكد من أن ملف الإضافة يتبع صيغة Plugins المعتمدة في المشروع.
